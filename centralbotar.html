Plantillas
Meta exige plantillas aprobadas para escribirle a un cliente que no te escribió en las últimas 24 horas. Se crean en Meta y acá las registrás para usarlas en campañas.
¿Cómo se crea una plantilla en Meta?
  1. Entrá a business.facebook.com → Administrador de WhatsApp → Plantillas de mensajes → Crear plantilla.
  2. Categoría: Marketing (ofertas) o Utilidad (avisos de un servicio).
  3. Nombre y idioma: tienen que ser idénticos a los que cargues acá.
  4. Pegá el texto (botón «Copiar texto para Meta» al guardar la plantilla acá) y enviala a revisión. Suele aprobarse en minutos.
  5. Cuando Meta la apruebe, volvé y cambiá el estado a Aprobada.

Preguntas frecuentes

Números de WhatsApp
Cada número conectado es una «línea». Podés tener varios en la misma cuenta (por ejemplo Seguridad Oeste y RavenTechs).
⚠️ Conexión vieja con el token a la vista.
Hay un token guardado de la versión anterior en los datos del negocio. Volvé a conectar ese mismo número acá abajo: se mueve a un lugar seguro y el viejo se borra.

Conectar un número

¿Dónde saco el Phone Number ID y el token?
  1. En developers.facebook.com → tu app → WhatsApp → Configuración de la API: ahí está el Phone Number ID del número.
  2. El token de prueba dura 24 h. Para uno permanente: business.facebook.com → Configuración → Usuarios del sistema → creá uno (Admin) → Generar token con los permisos whatsapp_business_messaging y whatsapp_business_management.
  3. Al conectar, el panel te muestra la URL del webhook y el token de verificación: pegalos en tu app de Meta → WhatsApp → Configuración → Webhook y suscribite al campo messages.
